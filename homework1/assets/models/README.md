# 模型文件目录

请将您下载的 glTF 模型文件放在此目录中。

## 使用说明

1. **下载模型**：
   - 访问 [Sketchfab](https://sketchfab.com) 或其他 3D 模型网站
   - 下载 glTF 或 GLB 格式的模型文件

2. **重命名文件**：
   - 将下载的模型文件重命名为 `downloaded_scene.glb` 或 `downloaded_scene.gltf`
   - 推荐使用 `.glb` 格式，文件更小且加载更快

3. **放置文件**：
   - 将重命名后的文件放入此目录 (`/assets/models/`)

## 支持的格式

- `.glb` (推荐)
- `.gltf`

## 注意事项

- 确保模型文件大小合理（建议小于 50MB）
- 如果模型包含纹理，请确保纹理文件路径正确
- 某些复杂模型可能需要较长的加载时间
